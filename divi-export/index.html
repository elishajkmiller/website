Divi export: Art: Outside the Box

This is the consolidated page below, exactly as it would be pasted into Divi. Placeholder photos, names and links are samples.

  1. In Divi, add a Fullwidth Section, then a Fullwidth Code module.
  2. Click Copy code in the top bar and paste it into the module.
  3. Replace the sample photos, names and links. The top comment in the code explains how.
