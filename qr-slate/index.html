How it goes on your site (Divi), step by step

The page is plain content, with no new plugin and no database. Whoever manages the site keeps editing it the same way as the Meet the Board page.

  1. Set up a safe place to work. Use a staging copy if you have one. Otherwise I save the new page as a Draft so nothing shows publicly.
  2. Upload the images. Add the sponsor logos and the artwork photos to the Media Library.
  3. Create the page. Pages, Add New, then name it "Art: Outside the Box".
  4. Add the layout. Open it in Divi and add a Fullwidth Section with a Fullwidth Code module.
  5. Paste the code. Copy it from the export page and paste it into the module.
  6. Swap in the real content. Replace the sample photos, titles, artist names, headshots and website links. Notes at the top of the code show how, and each card is a separate block.
  7. Check it on a phone, then Publish.
  8. Point the QR at the final page. I make the slate with that exact address and send it for printing.

Later, adding, fixing or removing an artwork is editing one block in the same module.
